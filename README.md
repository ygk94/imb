# Prédiction du score OFF (Kaggle)

Régression du score OFF par visite, évaluée en RMSE. Validation croisée groupée par patient.

Les données Kaggle ne sont pas versionnées : placer `X_train.csv`, `y_train.csv`, `X_test.csv` et `sample_submission.csv` à la racine.

```
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```
